# Reconstructing Missing Segments in Wrist Bioimpedance Waveforms

Companion code and numerical records for **Reconstructing Missing Segments in
Wrist Bioimpedance Waveforms**, by Babak Bayanian, Bahram Tarvirdizadeh,
Khalil Alipour, and Mohammad Ghamari.

This exploratory study compares 12 fixed reconstruction implementations and
evaluates real/synthetic training for six neural models on six participants.
The task is offline reconstruction of simulated dropouts in a wrist
bioimpedance channel. The cohort was reused after a pilot; the results have no
independent cohort or physiological validation.

## What is included

- Original experiment runners, model implementations, and 16 existing tests.
- Adapted SAITS source, its MIT license, exact upstream revision, and provenance.
- Published-run numerical records under `results/reference/outputs/`: fold and
  window metrics, training/validation logs, selection records, participant and
  seed summaries, sensitivity results, and descriptive bootstrap intervals.
- Data-download instructions, reproducibility checks, and plotting/audit scripts.

Raw recordings are obtained separately from PhysioNet. Checkpoints and synthetic
waveform caches are generated by the experiment runners. The numerical records
are distinct from these generated waveform and model files.

## Environment and installation

The recorded experiment used Python 3.13.5, NumPy 2.2.4, SciPy 1.15.2,
PyTorch 2.9.1+cu128, CUDA 12.8, and an NVIDIA RTX 4070 Ti SUPER.
CPU execution is supported; full training is substantially slower on CPU.
Exact GPU fitting is not guaranteed to be bitwise reproducible.

```sh
python -m venv .venv
# Windows PowerShell: .venv\Scripts\Activate.ps1
# Linux/macOS: source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

To reproduce the recorded CUDA package variant, install PyTorch with
`python -m pip install torch==2.9.1 --index-url https://download.pytorch.org/whl/cu128`
before installing the other requirements. For SVG plotting, also install
`python -m pip install -r requirements-figures.txt`.

## Check the included code and results

From the repository root:

```sh
python -m unittest -v test_bioz_inpainting test_validated_benchmark test_synthetic_augmentation test_augmentation_engine
python tools/verify_reference_results.py
```

The tests cover hidden-value invariance, visible context, receptive support,
participant separation, epoch selection, synthetic generation, and execution
equivalence. The reference checker validates source hashes, reconciles saved
fold/window metrics, recomputes participant MAE, and checks paired participant
bootstrap intervals. These checks do not retrain the models.

## Data

Use [Graphene Bioimpedance Tattoos v1.0.0](https://physionet.org/content/bp-graphene-bioimpedance/1.0.0/)
([dataset DOI](https://doi.org/10.13026/ce62-pc98)). Follow its ODC-By 1.0 terms
and cite the dataset and associated paper when using the recordings.

The supplied helper downloads the 17 baseline/rest BioZ CSV files used by this
study, preserving relative paths and verifying their recorded SHA-256 hashes:

```sh
python tools/download_data.py --list
python tools/download_data.py
```

Alternatively, extract the original dataset into `work/physionet_bioz/` so that
directories such as `subject1_day1/` occur beneath that path. The benchmark uses
BioZ1 only. Six participants provide 340 overlapping scoring windows; repeated
runs, gaps, masks, and synthetic windows do not increase the participant count.

## Reproduce the original 12-method comparison

```sh
python validated_benchmark.py --data work/physionet_bioz --max-epochs 60 --check-every 5 --steps 12 --seeds 2026 2027 2028 2029 2030 --output outputs/bioz_metrics_validated.csv
python work/summarize_validated.py
```

The methods are linear interpolation, filtered prefill, PCHIP, harmonic
reconstruction, GP mean and GP draw, a dilated 1D U-Net, compact SAITS,
conditional VAE, conditional GAN, conditional flow matching, and conditional
diffusion. The neural implementations are application-specific configurations.

Each outer participant is held out throughout fitting and selection. Four
participants supply inner training and one supplies validation. Validation
identity rotates across seeds 2026–2030. Each neural model selects an epoch on
real validation MAE and is reinitialized for refitting on the five outer-training
participants. Testing uses three fixed mask schedules and gaps of 62, 125, and
250 samples at 125 Hz (0.496, 1, and 2 seconds).

Native-rate masking precedes resampling and filtering. Visible input samples
alone determine normalization. The primary peak detector uses prominence 0.35,
35-sample separation, and 19-sample (152 ms) tolerance. Sensitivity crosses three
prominences and three tolerances, with the three mask schedules.

## Reproduce the paired augmentation experiment

```sh
python augmentation_sweep.py --data work/physionet_bioz --workers 2 --max-epochs 120
python work/audit_aug_sweep.py
python work/summarize_aug_sweep.py
```

Use `--workers 1` on machines with limited memory. The default sweep runs all
six held-out participants and five seeds, fitting all six neural methods in
both conditions: 360 final model fits. Completed cases are reused on resumption.
Generated files go to `outputs/` and `work/`, separately from the included
`results/reference/` records.

The augmented condition has a 1:1 real/synthetic mixture. The control presents
each real window twice with independent masks, matching epoch size and maximum
budget. Training-fitted harmonic/residual simulators exclude the validation and
test participants as appropriate. Both conditions validate on real recordings
with a 120-epoch cap. Actual selected update counts can differ.

The full audit requires the recordings and newly generated model/waveform
caches. It checks generator fitting, synthetic samples, checkpoint selection,
prediction replay, primary outcomes, and detector sensitivity.

## Saved findings and interpretation

In the original comparison, harmonic reconstruction had the lowest observed
mean MAE; descriptive intervals against U-Net included zero. In the separate
paired augmentation experiment at two seconds, U-Net MAE changed from 16.36 to
15.54 mΩ: a difference of −0.82 mΩ, with descriptive 95% participant-bootstrap
interval −1.39 to −0.35. VAE and GAN also improved mean MAE; flow matching and
diffusion worsened in every participant. Positive macro-F1 contrasts had
intervals including zero.

The six paired participant values, after averaging seeds and masks, are the
bootstrap units. Intervals are conditional on fitted models and are unadjusted
for multiplicity or method selection. The task uses future visible context and
simulated gaps. These results establish neither clinical utility nor hardware
transfer or glucose-estimation accuracy.

## Repository layout

- `bioz_inpainting.py`: preprocessing, masks, shared CNNs, GP and scoring helpers.
- `validated_benchmark.py`: 12-method evaluation and training-only selection.
- `synthetic_augmentation.py`: simulator and paired experiment implementation.
- `augmentation_case.py`, `augmentation_engine.py`, `augmentation_sweep.py`:
  full-cohort execution.
- `vendor/saits/`: attributed upstream adaptation and license.
- `work/`: selected numeric summary, audit, and SVG plotting scripts.
- `results/reference/`: recorded outcomes and portable manifests.
- `tools/`: data access and reference-result checks.

`python work/plot_validated.py` and `python work/plot_aug_sweep.py` produce SVG
figures after regenerating predictions and summaries.
